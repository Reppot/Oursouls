# Тёмная fashion-студия — внедрение 14.11.2026

Позднее все60 вырезок заменены подготовленными масками, а вешалка получила предзагрузку, плавное движение и светлую диагональную подложку. Актуальные сведения: [garment-masks.md](garment-masks.md).

## Изменения

- Общая тема Onest/графит/хвойный: главная, каталог, товар, конструктор, корзина, услуги, бренд, подвал и диалоги.
- Компактная шапка: каталог, конструктор, дополнительное меню, корзина/поиск. Главная остаётся только вешалкой с60 опубликованными товарами, без счётчика.
- Каталог без декоративных карточек/категорий/повторных кнопок: фотография, имя и цена; фильтры раскрываются на всех ширинах, ссылка поиска открывает панель.
- Галерея изделия: одно основное фото и реальные миниатюры; оригиналы доступны без JavaScript.
- В конструкторе дополнительные операции перенесены в меню проекта, добавление макета в корзину — на этап заказа. Технический бейдж2D и рекламные подписи удалены.
- У Canvas и миниатюр отдельный тёмный фон отображения; экспортные изображения по-прежнему имеют нейтральный фон.
- Вместо удаления всех похожих на фон цветов применяется связанная сегментация по краям изображения с foreground/background seeds для центрированных студийных снимков. Меняется alpha, исходные RGB принта не перекрашиваются. Работа маски ограничена480px и вынесена в Worker; ограничение очереди/кэша сохранено. Уже подготовленные прозрачные изображения не переделываются.

## Проверено

- Python12/12 и Node16/16, включая новые проверки сохранения белой ткани и светлого фрагмента принта.
- Smoke магазина: каталог, защищённая админка, поиск, фото, цена, скидка, скрытие товара, корзина.
- Desktop1440px: основные страницы без переполнения, фильтры, дополнительное меню/Escape.
- Mobile390px: основные6страниц без горизонтального переполнения, все3этапа конструктора, раскрытие/закрытие фильтров, диалог заказа.320px: шапка/меню и фильтры проверены после завершения адаптивной раскладки.
- Чистая сессия: поиск ПАПА → 1товар → размер → корзина → диалог → валидная ZIP-сигнатура PK0304.
- Чистая мобильная сессия: загрузка PNG → 1/10 → градиент → заказ → архив5.27MB; фон reviewCanvas тёмный, диалог по ширине помещается.
- Визуально проверены все8белых футболок: ткань и принты сохранены, прямоугольная подложка отсутствует.
- Worker реально загружен при обработке необработанного фото. Полноразмерные фотографии готовятся только в окне рейла; на старте7источников.

## Практические пределы

- Сегментация настроена на нынешние центрированные студийные фотографии. Новые lifestyle-снимки требуют подготовленного прозрачного rack_image.
- У прежних прозрачных rack-assets подрезан внешний alpha-контур средствами SVG при отображении. На некоторых широких светлых участках края кайма ещё заметна. Исходники сохранены; для идеального результата нужны аккуратные подготовленные альфа-маски этих исходников.
- Физический iPhone/Android и длительный FPS/память benchmark не выполнялись. Проверки мобильных размеров — браузерная эмуляция.
- В текущих локальных товарах нет снимков спины для проверки реального многокадрового товара; навигация галереи реализована без вымышленных фото.

## Проверка выпуска

Flask/Python compilation, JS syntax, whitespace diff и просмотр изменений — PASS. Отдельных frontendbuild, TypeScript и настроенного линтера нет; покрытие не измерялось. Новых ключей/секретов/платных API не добавлено. Проверка Render после отправки фиксируется в результате задачи.
